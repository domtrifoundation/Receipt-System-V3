# Preprocessing API — third-party runtime dependencies beyond `common/requirements.txt`.
#
# opencv-python and pymupdf have no prebuilt wheel for Python 3.15 yet (3.15 is still beta as
# of this writing) — confirmed directly: installing against a 3.15 interpreter falls through to
# a from-source build that fails on an unrelated linker issue, i.e. no compatible wheel exists
# at all. That is why this package is NOT in `noxfile.py`'s `FORWARD_COMPAT_DEPS` list — adding
# it there would just fail the same way — and why every test module here that imports one of
# these guards the import with `pytest.importorskip` instead.
